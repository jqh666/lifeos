# LifeOS · 发布产物

这是 LifeOS（个人人生操作系统 PWA）的**静态构建产物**仓库，通过 GitHub Pages 提供访问：

**https://jqh666.github.io/lifeos/**

- 仓库内只有构建产物（index.html / assets / sw.js / manifest / icons），**不含源码**。
- 所有记录只保存在你自己的浏览器（IndexedDB），本站不收集、不上传任何数据。
- AI 模型密钥在页面「设置 → 模型管理」中本地保存（加密后写入浏览器），不在此仓库中。
- 想要离线可用，可在手机浏览器里「添加到主屏幕」安装为 PWA。
